# 海外言語での探索ガイド

英語と日本語だけでは、特定の地域・言語圏で一次研究や実践が先に進んでいる分野に届かないことがある。題材に応じて原産言語や主要言語圏を広げ、現地語の一次情報までたどるための手順をここにまとめる。

## 1. 掘る言語圏を選ぶ（0周目）

- 既定の2本（英語＋日本語）に固定せず、問いの性質から**一次資料が生まれている言語圏（原産言語）**を見立てる。
- 検索役の同時起動は2本までの境界を守り、0周目は「英語＋原産言語（または日本語）」、1周目以降で別の言語圏へ広げるなど、**周を分けて言語圏を割り当てる**。
- 飽和（7割）を数える対象は同じ問いを違う探し方で探した検索役どうしに限る。別の言語圏へ広げた周で新しい一次資料がまとまって出た場合は、言語圏ごとの未開拓としてそのまま掘る。

---

## 2. 直訳を避け、現地用語を拾う

日本語や英語の検索語をそのまま直訳しても、現地の界隈や学会で使われている呼び方と外れることが多い。次の順で**現地用語（native terminology）**を拾ってから引き直す。

1. **多言語版 Wikipedia の言語リンク**: 英語版や日本語版の記事から対象言語版へ切り替え、記事題名・見出し・References（脚注）にある現地語と定番資料を拾う。
2. **論文・公式仕様のキーワード**: OpenAlex や原著の抄録にある現地語のキーワード・タグを拾う。
3. **`map.md` に言語つきで記録**: `## 用語` に `<現地用語>（<言語>・<日本語の呼び方>）— <出典>` の形で残し、次の周の「言葉で引き直す」に使う。

## 3. 言語圏ごとの一次情報・媒体の目安

媒体は固定の一覧から選ばず0周目で探すのが原則だが、見当がまったくつかないときの出発点として次を目安にする。

| 言語圏 | 学術・一次資料リポジトリ | 実践記録・技術・コミュニティ媒体 |
|---|---|---|
| 中国語（簡体・繁体） | arXiv（中華圏著者ページ）、CNKI（抄録・無料公開分）、国家哲学社会科学文献中心 | 知乎（Zhihu）、CSDN、Bilibili（解説動画）、個人ブログ・GitHub |
| 韓国語 | KCI（Korea Citation Index）、大学リポジトリ | Velog、Tistory、Naver D2 / Blog、YouTube |
| ドイツ語 | 大学リポジトリ（OPUS 等）、技術報告・規格解説 | heise online、専門フォーラム、個人ブログ |
| フランス語 | HAL（`hal.science`、`fetch.py` は PDF 再取得に対応）、OpenEdition、Persée | 技術ブログ、専門誌アーカイブ |
| スペイン語・ポルトガル語 | SciELO、Redalyc、Dialnet | 大学・研究機関の公開資料、技術ブログ |
| ロシア語 | CyberLeninka（OA 論文） | Habr、専門フォーラム |
| アラビア語・その他 | 各言語版 Wikipedia の References、大学・公的機関の一次発表 | 現地語公式ドキュメント・YouTube |

※ ログイン必須の SNS（小紅書など）や有料データベースは境界どおり回避せず、ログイン不要の別置き場を探すか、URL を並べてユーザーへ渡す。

## 4. 海外言語の取得・照合・表示のコツ

- **文字コード・IDN**: `fetch.py` は UTF-8・宣言 charset・HTML の `lang` ヒントに基づく主要コードページ（GB18030 / Big5 / CP949 / CP1251 / CP1252 / CP1256 等）へ自動でフォールバックし、国際化ドメイン名（IDN）も Punycode 変換したうえで SSRF 検査と取得を行う。
- **PDF の短さ下限と OCR**: 日本語・中国語・韓国語（ハングル）が3割を超える PDF は 1,000 字下限で判定される。文字層の無いスキャン PDF で確信度不足の `FAIL` が出たら、言語に合わせて `IMOZURU_OCR_LANG` を指定して取り直す（例: `IMOZURU_OCR_LANG=chi_sim+eng`、`kor+eng`、`deu+eng`、`fra+eng`、`rus+eng`、`ara+eng`）。
- **YouTube 字幕**: `fetch.py` は日本語・英語の手動字幕→動画の元言語（`zh-Hans` などサブタグつきの完全なタグ）の手動字幕→元言語の自動字幕の順で取得する。特定の言語を優先したいときは `IMOZURU_YT_LANGS=zh-Hans,en` のように環境変数で指定でき、字幕が複数あればその並び順で選ぶ（`all`・`live_chat` は指定不可）。
- **引用照合（`report.py` / `digest.py`）**: 照合前に Unicode の NFC 正規化を行うため、仏・独・西・韓などの合成/分解差で落ちにくい。引用は翻訳せず原文のまま切り出す。
- **抜き書きの表示（`extracts.json`）**: 日本語以外の原文には `ja` に日本語訳を添える。必要なら `"lang"`（例: `"zh"`, `"ko"`, `"de"`, `"fr"`, `"ru"`, `"ar"`）を付けると、`report.html` の書体選択やアラビア語・ヘブライ語の右横書き（`dir="auto"`）が正確に当たる（省略時は文字種から自動推定される）。
